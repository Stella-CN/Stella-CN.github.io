# Stella-CN 的个人博客

这是 Stella-CN 的 GitHub Pages 个人网页博客，用于介绍自己、展示项目作品和记录学习文章。

## 在线访问

部署成功后可访问：

```text
https://stella-cn.github.io
```

## 文件说明

- `index.html`：网站首页内容
- `styles.css`：页面样式
- `script.js`：导航交互和年份更新

## 如何继续完善

你可以直接编辑 `index.html` 中的内容：

1. 修改“关于我”中的个人介绍
2. 在“项目展示”中替换成真实项目链接
3. 在“最新文章”中添加博客文章入口
4. 将 `mailto:hello@example.com` 替换为你的真实邮箱，或删除邮件按钮

## GitHub Pages 设置

在仓库的 **Settings → Pages** 中选择：

- Source: `Deploy from a branch`
- Branch: `main`
- Folder: `/root`

保存后等待几分钟即可发布。
